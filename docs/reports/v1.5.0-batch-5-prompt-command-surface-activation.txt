An agent following the prompt would have produced an undeclared TRN and any RSP tracing to it would have been blocked (UPSTREAM_TRACE_MISSING). Fix in src/traceChecker.ts: the declaration regex already requires "ID:" at line start, so real link lines ("REQ-001 -> BEH-999") never match it; the blanket "->" skip was removed. No existing src/tests/docs line relied on the skip. Regression tests assert the prompt's taught declarations are all recognized, that a link line declares nothing, and that a declaration containing "->" does.
